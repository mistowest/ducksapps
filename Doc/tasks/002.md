## Objetivo
Implementar a camada de transporte HTTP com os headers corretos, base URLs e tratamento de autenticação baseado nas evidências encontradas no app.

## Contexto (leitura obrigatória)
- Doc/analysis/00-overview.md
- Doc/analysis/02-rede.md
- Doc/analysis/03-auth.md
- Doc/templates/endpoint-template.md

## Especificação
Com base na análise do app, implementar um cliente HTTP que reproduza exatamente as chamadas de rede do app oficial.

### Assinaturas das funções/classes a criar
- `class DucksHttpClient` - Cliente HTTP principal
- `DucksHttpClient(String baseUrl)` - Construtor com URL base
- `Future<Response> get(String endpoint, {Map<String, String> headers = const {}})`
- `Future<Response> post(String endpoint, {dynamic body, Map<String, String> headers = const {}})`
- `Future<Response> put(String endpoint, {dynamic body, Map<String, String> headers = const {}})`
- `Future<Response> delete(String endpoint, {Map<String, String> headers = const {}})`
- `void setAuthToken(String token)` - Define o token de autenticação
- `void clearAuthToken()` - Remove o token de autenticação

### Valores exatos
- **Base URLs confirmadas**:
  - `https://api.duckapps.com.br` (API principal)
  - `https://api.aminoapps.com.br` (API Amino Apps)
  - `https://cdn.duckapps.com.br` (CDN para mídia)
  - `https://vmi3521716.contaboserver.net` (API alternativa?)
- **Endpoints específicos**:
  - `/bootstrap` (aminoapps)
  - `/config` (aminoapps)
  - `/apoie` (duckapps)
  - `/reset-password` (duckapps)
  - `/email-changed` (duckapps)
- **Headers obrigatórios**:
  - `Authorization: Bearer <token>` (quando autenticado)
  - `X-Client-Info: postgrest-dart/2.7.1` (identificação da biblioteca)
  - `Content-Type: application/json` (para requisições com body)
- **Método de autenticação**: Bearer token no header Authorization
- **Formato do token**: JWT com algoritmo HS256, emitido por supabase

### Algoritmos em pseudocódigo
```
// Inicialização do cliente
DucksHttpClient client = DucksHttpClient('https://api.duckapps.com.br');

// Definir token após login
client.setAuthToken('jwt_token_here');

// Fazer requisição autenticada
final response = await client.get('/apoie', headers: {
  'Authorization': 'Bearer $token',
  'X-Client-Info': 'postgrest-dart/2.7.1',
});

// Requisição sem auth (configuração inicial)
final configResponse = await client.get('/config', headers: {
  'X-Client-Info': 'postgrest-dart/2.7.1',
});
```

### Regras de erro
- Lançar `UnauthorizedException` para status 401
- Lançar `ForbiddenException` para status 403
- Lançar `NotFoundException` para status 404
- Lançar `BadRequestException` para status 400
- Lançar `InternalServerErrorException` para status 500+
- Implementar retry automático para status 429 (rate limit) com backoff exponencial
