### Valores exatos (baseados nas análises até agora)

#### De Doc/analysis/04-usuarios.md - Modelo de Dados: Usuario
- id: string (UUID)
- email: string
- role: string (anon, member, moderator, admin)
- created_at: string (ISO 8601 datetime)
- is_ducks_plus: boolean
- duck_id: string (opcional, para integração com DuckID)

#### De Doc/analysis/03-auth.md - Estrutura do Token JWT
- Header: {"alg":"HS256","typ":"JWT"}
- Payload: {"role":"anon","iss":"supabase","iat":1780872644,"exp":2096232644}
- Algoritmo: HS256
- Issuer: supabase

#### Estruturas de resposta inferidas dos endpoints:
- POST /token: { access_token, refresh_token, user?: User }
- GET /me: { id, email, role, created_at, is_ducks_plus, duck_id? }
- POST /refresh: { access_token, refresh_token }

### Algoritmos em pseudocódigo
```
// Modelo User
class User {
  final String? id;
  final String? email;
  final String? name;  // Adicionado baseado em padrões comuns
  final String? role;
  final DateTime? createdAt;
  final bool? isActive; // ou is_ducks_plus conforme 04-usuarios.md
  final String? duckId; // opcional
  
  factory User.fromJson(Map<String, dynamic> json) => User(
        id: json['id'] as String?,
        email: json['email'] as String?,
        name: json['name'] as String?, // campo comum em APIs
        role: json['role'] as String?,
        createdAt: json['created_at'] != null
            ? DateTime.parse(json['created_at'] as String)
            : null,
        isActive: json['is_active'] as bool? ?? json['is_ducks_plus'] as bool?,
        duckId: json['duck_id'] as String?,
      );
      
  Map<String, dynamic> toJson() => {
        'id': id,
        'email': email,
        'name': name,
        'role': role,
        'created_at': createdAt?.toIso8601String(),
        'is_active': isActive,
        'duck_id': duckId,
      };
}

// Modelo AuthResponse
class AuthResponse {
  final String accessToken;
  final String? refreshToken;
  final User? user;
  
  factory AuthResponse.fromJson(Map<String, dynamic> json) => AuthResponse(
        accessToken: json['access_token'] ?? json['token'],
        refreshToken: json['refresh_token'],
        user: json['user'] != null ? User.fromJson(json['user']) : null,
      );
}

// Modelo TokenResponse
class TokenResponse {
  final String accessToken;
  final String? refreshToken;
  
  factory TokenResponse.fromJson(Map<String, dynamic> json) => TokenResponse(
        accessToken: json['access_token'] ?? json['token'],
        refreshToken: json['refresh_token'],
      );
```

### Regras de erro
- Lançar exceção apropriada quando JSON não puder ser convertido para o modelo
- Tratar campos opcionais com segurança (null safety)
- Validar formatos quando possível (ex: email, UUID, datas ISO 8601)
