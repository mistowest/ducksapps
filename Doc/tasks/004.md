## Especificação
Com base na análise do app, implementar um serviço de autenticação que reproduza exatamente o fluxo de auth do app oficial.

### Assinaturas das funções/classes a criar
- `class AuthService` - Serviço principal de autenticação
- `AuthService(this._httpClient, this._storage)` - Construtor com injeção de dependências
- `Future<User> login(String email, String password)` - Realiza login e retorna usuário autenticado
- `Future<void> logout()` - Remove autenticação e limpa dados
- `Future<User> refreshToken()` - Renova o token usando refresh token
- `Future<bool> isAuthenticated()` - Verifica se o usuário está autenticado
- `User? getCurrentUser()` - Retorna o usuário atualmente autenticado
- `Stream<User> authStateChanges()` - Stream para ouvir mudanças no estado de auth

### Valores exatos
- **Endpoints de auth** (inferidos):
  - `POST /token` - Para obtenção de token (com grant_type provavelmente)
  - Possivelmente: `/login`, `/signup`, `/logout` (não encontrados diretamente, mas padrão comum)
- **Formato do token**: JWT com:
  - Algoritmo: HS256
  - Issuer: supabase
  - Claims identificados: role (anon), iat, exp
- **Headers de auth**:
  - Authorization: Bearer <jwt_token>
  - X-Client-Info: postgrest-dart/2.7.1
- **Tratamento de tokens**:
  - Strings indicando: get_token_null, get_token_error, refresh_token
  - Estados: unauthenticated, not_authenticated, authentication_required, unauthorized
  - Integração com FCM para tokens de push: Messaging#getToken, Messaging#onTokenRefresh

### Algoritmos em pseudocódigo
```
// Login
final response = await httpClient.post('/token', body: {
  'grant_type': 'password',
  'username': email,
  'password': password,
}, headers: {
  'X-Client-Info': 'postgrest-dart/2.7.1',
});

// Extrair token da resposta
final token = response.data['access_token'];
final refreshToken = response.data['refresh_token'];

// Salvar token seguramente
await _storage.write('access_token', token);
await _storage.write('refresh_token', refreshToken);

// Notificar mudança de estado
_authController.add(User.fromJson(response.data['user']));

// Refresh token
final refreshResponse = await httpClient.post('/token', body: {
  'grant_type': 'refresh_token',
  'refresh_token': refreshToken,
});

// Processar resposta similar ao login

// Logout
await _storage.delete('access_token');
await _storage.delete('refresh_token');
_authController.add(null);
```

### Regras de erro
- Lançar `InvalidCredentialsException` para status 401 em login
- Lançar `AuthException` para outros erros de autenticação
- Tratar erros de rede com retry apropriado
- Implementar detecção de token expirado baseado no claim 'exp' do JWT
- Quando token expirar automaticamente tentar refresh se refresh token disponível
