## Especificação
Com base na análise do app, implementar um serviço de usuários que reproduza exatamente os endpoints relacionados à gestão de usuários do app oficial.

### Assinaturas das funções/classes a criar
- `class UserService` - Serviço para endpoints de usuários
- `UserService(this._httpClient, this._authService)` - Construtor com injeção de dependências
- `Future<User> getMe()` - Obtém dados do usuário autenticado
- `Future<void> logout()` - Realiza logout (chama AuthService.logout)
- `Future<User> refreshToken()` - Renova o token de acesso

### Valores exatos (baseados em 04-usuarios.md)
- **Endpoints**:
  - `GET /me` - Para obtenção de dados do usuário
  - `POST /logout` - Para logout (opcional, pode ser feito localmente)
  - `POST /refresh` - Para refresh de token (alternativa ao /token com grant_type=refresh_token)
- **Headers obrigatórios**:
  - Authorization: Bearer <access_token>
  - X-Client-Info: postgrest-dart/2.7.1
- **Modelo de dados: Usuario**:
  - id: string (UUID)
  - email: string
  - role: string (anon, member, moderator, admin)
  - created_at: string (ISO 8601 datetime)
  - is_ducks_plus: boolean

### Algoritmos em pseudocódigo
```
// Get me
final response = await httpClient.get('/me', headers: {
  'Authorization': 'Bearer $accessToken',
  'X-Client-Info': 'postgrest-dart/2.7.1',
});

// Extrair dados do usuário
final user = User.fromJson(response.data);

// Logout (pode ser feito localmente ou via endpoint)
await authService.logout();

// Refresh token
final response = await httpClient.post('/refresh', body: {
  'grant_type': 'refresh_token',
  'refresh_token': refreshToken,
}, headers: {
  'Content-Type': 'application/json',
  'X-Client-Info': 'postgrest-dart/2.7.1',
});

// Processar resposta similar ao login em auth_service
```

### Regras de erro
- Lançar `NotAuthenticatedException` se não houver token válido
- Lançar `UserServiceException` para outros erros de serviço de usuário
- Tratar erros específicos de endpoints (404 para /me não encontrado, etc.)
