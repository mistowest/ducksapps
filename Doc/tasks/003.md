## Objetivo
Implementar a estrutura básica de camadas do app baseado na arquitetura identificada, incluindo navegação e organização de serviços.

## Especificação
Com base na análise do app, implementar uma estrutura de camadas que reproduza a organização identificada no app oficial.

### Assinaturas das funções/classes a criar
- `abstract class BaseService` - Classe base para todos os serviços
- `class AuthService extends BaseService` - Serviço de autenticação
- `class ApiService extends BaseService` - Serviço genérico de API
- `class NavigationService` - Serviço de navegação (simplificado)
- `class Locator` - Injetor de dependência simples (service locator)
- `enum Route { home, login, community, profile, settings }` - Rotas do app

### Valores exatos
- **Serviços identificados**:
  - Serviço de push notifications (`package:ducks/core/services/push_notification_service.dart`)
  - Serviço de relatório de erro (`package:ducks/core/services/relatorio_de_erro.dart`)
  - Possível estrutura de serviços core
- **Mecanismo de estado**: Indicações de uso de notificações para gerenciamento de estado
- **Navegação**: Uso de GoRouter ou similar com rotas identificadas
- **Plataforma Channels**: Canal específico identificado "ducks_id"

### Algoritmos em pseudocódigo
```
// Inicialização do service locator
final locator = Locator();
locator.registerLazySingleton<AuthService>(() => AuthService());
locator.registerLazySingleton<ApiService>(() => ApiService());
locator.registerLazySingleton<NavigationService>(() => NavigationService());

// Uso dos serviços
final authService = locator<AuthService>();
final isLoggedIn = await authService.isAuthenticated();

// Navegação
final navService = locator<NavigationService>();
await navService.pushRoute(Route.home);

// Serviço de API
final apiService = locator<ApiService>();
final response = await apiService.get('/apoie');
```

### Regras de erro
- Serviços devem lançar exceções específicas que podem ser tratadas pelas camadas superiores
- AuthService deve lançar AuthException para falhas de autenticação
- ApiService deve lançar ApiException para falhas de comunicação
- Todos os serviços devem tratar erros de rede de forma consistente

### Arquivos a criar ou alterar
- `Scripts/services/base_service.dart` - Classe base de serviços
- `Scripts/services/auth_service.dart` - Serviço de autenticação
- `Scripts/services/api_service.dart` - Serviço de API genérico
- `Scripts/services/navigation_service.dart` - Serviço de navegação
- `Scripts/locator.dart` - Injetor de dependência
- `Scripts/routes.dart` - Definição de rotas
- `Scripts/tests/test_services.dart` - Testes dos serviços
